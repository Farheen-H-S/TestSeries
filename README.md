# TestSeries

TestSeries is a web-based application designed to help CA students prepare for their examinations by generating customized practice test papers.

Users can upload ICAI Revision Test Papers (RTPs), from which the system automatically extracts questions and their corresponding suggested answers. Based on the selected subject, chapter, and number of questions, the application generates a randomized question paper along with a matching suggested answer sheet for effective self-practice.

Current Version:
- Revision Test Paper (RTP) support
- Automatic question and answer extraction
- Chapter-wise random paper generation
- PDF question paper generation
- PDF suggested answer sheet generation

Planned Future Enhancements:
- Previous Year Question (PYQ) support
- Mock Test support
- Multi-user authentication
- Cloud deployment
